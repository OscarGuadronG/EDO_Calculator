# Calculadora de Ecuaciones Diferenciales Ordinarias (EDO)
## **Introdución**
Esta calculadora utiliza métodos numéricos para realizar aproximaciones a soluciones de EDOs con condiciones iniciales.
esta versión tiene implementado 18 métodos distintos, ordenados de el método menos preciso hasta el método más preciso.
## **Requerimientos**
- Python 3.X
- StreamLit
- Sympy
- Numpy
- Pandas
## **Instalación**
- Clonar el proyecto
```bash
Git clone <URL_repositorio>
```
- Moverse a la carpeta del proyecto
```bash
cd <proyecto>
```
- Crear entorno virtual venv
```bash
python -m venv venv
```
- Activar entorno venv
```bash
```
Linux: 
```bash 
source venv/bin/activate
```
Windows: 
```bash
venv\Scripts\activate
```
- Instalar librerías requeridas
```bash
pip install -r requirements.txt
```
- Ejecutar poryecto
```bash
streamlit run app.py
```
## Uso
Una vez iniciada la aplicación, el navegador abrirá automáticamente la dirección:
http://localhost:8501
Desde allí podrás utilizar la calculadora.
